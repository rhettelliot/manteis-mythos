# MYTHOS — Personal Mythology Engine

A Manteis Systems construction. Answer seven questions. Receive a personal mythology.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS 3 (sharp corners, Swiss typography)
- Framer Motion (mechanical spring interactions)

## Design
- `#000000` black void
- `#FF4D00` Safety Orange
- `#007AFF` Signal Blue
- Zero border-radius. Glassmorphic panels with 24px backdrop blur.

## Develop
```bash
pnpm install
pnpm dev
```

## Deploy
Deployed via Vercel.
